# Шаблон Typst для робіт ХНУРЕ (v0.2.0)

Пакет для оформлення звітів до робіт за стандартами ХНУРЕ та ДСТУ 3008:2015. Заснований на [typst_nure_template].

## Встановлення локально
### Linux та macOS
```bash
git clone https://github.com/pencelheimer/typst-nure-template.git ~/.local/share/typst/packages/local/nure/0.2.0
```

### Windows
Встановіть Linux або купіть макбук та прочитайте попередній пункт.

## Нова архітектура

Замість монолітних шаблонів-обгорток з десятками параметрів, це версія пропонує підхід конструктора. Архітектура складається з двох основних компонентів:

1. **Глобальний стан (`config.setup`)**: глобальні параметри (тема, автори, викладачі) налаштовуються один раз.
2. **Структурні блоки (`parts`)**: документ збирається як конструктор із самодостатніх елементів (титульний аркуш, завдання, календарний план і т.д.).

Усі локальні дані (наприклад, текст реферату або таблиця календарного плану) передаються безпосередньо в конкретні функції, щоб не перевантажувати глобальний конфіг.

## Швидкий старт

Найпростіше почати новий проєкт скопіювавши вже існуючий, або скориставшись стандартним шаблоном за допомогою:
```bash
typst init @local/nure:0.2.0 project-name
```

Стандартна структура виглядає наступним чином:

```typst
#import "@local/nure:0.2.0": style, config, parts

// 1. Застосовуємо правила оформлення за ДСТУ
#show: style.dstu

// 2. Налаштовуємо спільні глобальні дані
#config.setup(
  title: "Структурування програми",
  work-number: 2,
)

// 3. Збираємо документ з блоків
#parts.report-title-page(
  work-type: "ПЗ",
  subject: "MGoL",
  edu-program: "ПЗПІ",
  authors: ((name: "Ситник Є. С.", group: "23-2", gender: "m"),),
  mentors: ((name: "Олійник О. В.", degree: "ст. викл.", gender: "f"),),
)

#parts.title-heading()
#v(-style.spacing)

== Мета роботи
Опис мети роботи...
```

Для курсових та інших робіт доступні додаткові модульні блоки:
- `#parts.coursework-title-page()`
- `#parts.task-list(source: [...], content: [...])`
- `#parts.calendar-plan(plan-table: [...])`
- `#parts.abstract(keywords: ("укр": "англ", ...))[Текст укр][Текст англ]`
- `#parts.table-of-contents()`

Усі функції та параметри задокументовані. Просто введіть `#parts.` у вашому редакторі, щоб побачити підказки.
